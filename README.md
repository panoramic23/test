# PHA.SE. Gestione Progetti (Demo)

Web app front-end (HTML/CSS/JS) con doppia area:

- **Area Dipendenti**: login, dashboard, calendario, alert, schede clienti collaborative, filtro stato, creazione nuovi clienti.
- **Area Master**: creazione dipendenti, assegnazione progetti, governance operativa.
- **Area Clienti**: vista semplificata della scheda progetto con documenti, attività, stato e contatti referente.

## Avvio locale

Apri `index.html` in un browser moderno oppure avvia un server statico:

```bash
python3 -m http.server 8080
```

Poi visita `http://localhost:8080`.
